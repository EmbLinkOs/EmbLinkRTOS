### Added (power management, 2026-11-09)

- SPEC-018, proposed: power management for M4.4. SoC states map to a generic set (IDLE, SLEEP, DEEP_SLEEP, OFF) with entry and exit latencies, what each loses and what keeps time in it. Threads and drivers hold wake-latency and timing-tolerance constraints; the idle path picks the deepest state that fits them, the next deadline and the watchdog, suspends and resumes devices in order, and corrects kernel time from the timebase that kept running. Residency is counted and exposed. Wake latency and residency are measured with the logic analyzer on both boards, 10,000 wakes per state; current is not measured until an instrument is on the bench ([SPEC-018](docs/specs/SPEC-018-power-management.md)).
