### Changed (file headers, 2026-11-13)

- Every C, assembly and linker-script source opens with the EmbLinkRTOS notice and a Doxygen block, `@file`, `@brief`, `@details`, `@see`, `@author` and `@date`, after its SPDX and copyright lines (CODING-STANDARD CS-11.1, `CONTRIBUTING.md`). The descriptions are the files' own, the brief their first sentence. The author and creation date come from each file's first commit, with `.mailmap` giving one name per person. The public headers' descriptions now appear on their API reference pages.
- `tools/dev/file_headers.py --write` converts a file written with a plain description comment, and `--check` runs in CI. Generated files get the same notice and `@file` block from `emb-hwgen`, with its stamp as their details.
- Python, CMake, Kconfig, YAML and shell files, and the tools' own configuration files, carry the same notice in `#` comments after their SPDX and copyright lines, without a Doxygen block. The generator writes it into its CMake, Kconfig and option files too.
