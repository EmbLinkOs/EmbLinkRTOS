# pico2_w

The console on UART0 at 115200 baud on GPIO0 (TX, pin 1) and GPIO1 (RX, pin 2). The CPU runs from the 12 MHz crystal, without the PLL, in this first increment. The user LED is on the CYW43439 wireless chip, which has no driver yet, so the board has no LED. Images are UF2 files, copied to the boot ROM's USB drive (hold BOOTSEL while plugging in).

| Core | cortex-m33f, port `cortex_m/armv8m-main` |
| CPU clock | 12 MHz from xosc |
