# nucleo_f446re

The STM32F446RE at 180 MHz from the PLL, its input the ST-LINK's 8 MHz MCO on PH0 in HSE bypass (solder bridges SB16 and SB50 as shipped). The console is USART2, which the ST-LINK carries as its virtual COM port.

| Core | cortex-m4f, port `cortex_m/armv7em` |
| Revision | MB1136 C-03 |
| CPU clock | 180 MHz from hse (bypass) |
| Console | usart2 at 115200 baud |
| Debug probe | openocd `board/st_nucleo_f4.cfg`, pyocd_target `stm32f446retx` |
