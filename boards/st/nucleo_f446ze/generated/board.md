# nucleo_f446ze

The STM32F446ZE (LQFP144) at 180 MHz from the PLL, its input the ST-LINK/V2-1's 8 MHz MCO in HSE bypass, the board's default clock configuration (UM1974 §6.7.1). The console is USART3 on PD8 and PD9, which the ST-LINK carries as its virtual COM port.

| Revision | MB1137 |
| CPU clock | 180 MHz from hse (bypass) |
| Console | usart3 at 115200 baud |
| Debug probe | openocd `board/st_nucleo_f4.cfg`, pyocd_target `stm32f446zetx` |
