# arduino_uno

The ATmega328P at 16 MHz from its crystal, with the Optiboot bootloader in the last 512 bytes of flash. The console is USART0 on PD0 and PD1, which the ATmega16U2 carries as the board's USB serial port; the user LED L is on PB5 (pin 13).

| Field | Value |
|---|---|
| SoC | ATmega328P (pdip28) |
| Core | avr5, port `avr/atmega328p` |
| Revision | R3 |
| CPU clock | 16 MHz from xtal |
| Console | usart0 at 115200 baud |
