# Arduino Uno: misuse faults executed on hardware (2026-11-05)

The second run of the conformance suite on the physical Uno, and the first with the fault checks executed instead of skipped ([A89](../specs/AMENDMENTS-M3.md)). **Board:** the same Smraza Uno R3 clone as on [2026-11-04](hil-uno-2026-11-04.md): ATmega328P at 16 MHz, Optiboot, ATmega16U2 USB. **Host:** macOS, port `/dev/cu.usbmodem11101`. **Programmer:** EmbCC's `embflash --stk500`.

**Build:** preset `avr-uno-hil`, at commit `cdd12f5` with a clean tree (branch `feat/fault-checks-on-target`): tiny profile, checked, crash record on, avr-gcc 14.4.0, configuration `3b582919390c2f6b`.

**Record:** `docs/engineering/hil-runs/2026-11-05-arduino_uno-checked/` holds each image's console (`<image>.log`) and record (`<image>.json`): the SHA-256 of the ELF and of the `.hex` embflash wrote, the commit, the times and every case line. `index.json` sums them. It is the first run filed by `tools/hil/archive.py`.

## What running the checks found

Three defects that only the board showed, fixed in the same change:
1. **The idle context's stack.** On AVR the idle loop runs on the stack `main()` ran on, and its interrupts run on top of it. It started below `main()`'s dead frames, within about 200 bytes of `.noinit`. The test framework's 16 retained bytes were enough to make a replay boot overrun the framework's variables: on EmbSIM, a write through a corrupted pointer, then a lockup. `emb_arch_kernel_start()` now restarts that stack at `RAMEND`.
2. **The runner's 256-byte stack.** `vsnprintf_P` deep in a case reached past it, into `embn_avr_current`, the port's current-context pointer. The next tick's epilogue then wrote through garbage. The framework's reset line and failure lines now print without the formatter. `crash_record_round_trip` used all 256 bytes, with a 60-byte record on the stack, so the crash tests keep their record in static storage.
3. **Output inside a case takes ticks.** A reset line printed mid-case let a 5-tick delayed work item expire on EmbSIM's NUCLEO, so the line now prints after its case.
